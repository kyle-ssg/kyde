Kyde

A fast, native IDE and Git client built around your coding agents.

Claude Code agents in parallel worktrees · live status · side-by-side diff · hunk staging · 3-way merge · GPU-rendered · written in Rust

Download View on GitHub

Run agents in parallel

Projects → worktrees → tabs, each tab an agent. Claude Code by default, or any agent CLI.

⎇

A worktree per agent

Each agent gets its own git worktree and branch, so parallel agents never trample each other's files. Ask a busy one for something unrelated and it moves itself to a clean worktree.

●

Live status

Working, done or needs you, on every worktree. A sound when one finishes and a key to jump to it, so you only look when an agent needs you.

🐙

Issues & PRs to agents

Start a GitHub issue or review a PR and get a fresh worktree with an agent already briefed. Issues and PRs render in-app with comments, commits, changed files and checks.

♾

Outlives the window

Every agent runs in its own background process. Quit Kyde and agents keep working; reopen and they're back where you left them.

🧹

Cleans up

Spots merged or finished work and closes its tabs and worktrees, so the sidebar only shows what's still in flight.

⌨️

Scriptable

ky agent … drives agents from the shell, so agents can start, brief and check on each other.

Side-by-side diff & 3-way merge

IDE-grade git tools to check what the agents wrote, keep the good hunks, settle the conflicts and ship it.

⇄

Visual hunk staging

Side-by-side diff with word-level highlighting and a center gutter to stage or revert hunks — git add -p, made visual.

⑂

3-way merge

Yours, result and theirs side by side. Apply every non-conflicting change in one click, then settle each conflict from the gutter.

🕘

History & safety nets

A git log with a commit graph and branches sidebar, push / pull / fetch from the toolbar, rollback, and local history that snapshots your files on save and before anything destructive.

The IDE, when you need it

For the fix you'd rather make yourself. No JVM, no Electron, no waiting.

🌳

Browse & edit

Folder tree, tabs, fuzzy Go to File and Find in Files, and tree-sitter highlighting for 16 languages with folding, error squiggles and ⌘-click to definition.

▮

Built-in terminal

A real PTY-backed multi-tab shell, with full colour, selection and copy/paste. Drop a file on it, or on an agent, to paste its path.

⚡

Instant & native

GPU-rendered on gpui, the framework behind Zed. Opens in a blink and scrolls a 37k-line file at 120fps.

🎨

Feels familiar

WebStorm or VSCode keymap with every shortcut rebindable, and an IDE-style dark theme plus light and colour-blind palettes.

Install

macOS — prebuilt Linux — prebuilt AppImage Windows — from source 
# macOS — download from Releases and drag Kyde.app to /Applications:
#   kyde-macos.zip          Apple Silicon
#   kyde-macos-x86_64.zip   Intel
# The build is Developer ID signed and notarized — no quarantine dance.

# Linux — download kyde-linux-x86_64.AppImage from Releases, then:
chmod +x kyde-linux-x86_64.AppImage && ./kyde-linux-x86_64.AppImage

# or build from source (any platform)
cargo build --release
